# An undocumented interval is written down, not left out

Where the chain of custody has a gap, the corpus carries a node for the gap: the interval, the
last documented holder before it, the first after, and what has been searched without result.
The claim is `[open]`. It is not omitted, and it is not smoothed over by adjacent events
sitting next to each other in a list.

This is the discipline the field already asks for. Museum provenance standards single out the
1933–1945 period in continental Europe precisely because an *unexplained* gap there is
material, and publishing "provenance unknown for this period" is the expected disclosure
rather than an embarrassment to be tidied.

The general form is what this augmentation asks for: a gap that nobody has written down is
indistinguishable from a gap nobody has looked for.
