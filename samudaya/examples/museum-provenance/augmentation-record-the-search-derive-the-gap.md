# Record the search; derive the gap

A gap in custody is the absence of a documented transfer between two dated ones. It should be
**computed** from the custody events, never stored as a node of its own.

A stored gap can be asserted where the record does not entail one, and it can be closed by
deleting a file — which is the failure this domain can least afford, because in provenance the
gap is not missing metadata, it is the research result.

But a derived gap carries only half of what matters, and the missing half is the reason this
augmentation exists. *No transfer is documented between 1931 and 1949* and *we searched four
archives for a transfer between 1931 and 1949 and found none* are different findings, and no
absence can distinguish them. The first is a property of the record. The second is a claim
about work that was done, and it is positive information that nothing else in the corpus
encodes.

So: the gap is a query, and **the search is a document**. A negative result is a finding with
an author, a date and a scope, and it is recorded the same way a positive one is. A gap nobody
has written a search against is indistinguishable from a gap nobody has looked at — and the
fix for that is not to invent a node for the gap, it is to record the looking.
