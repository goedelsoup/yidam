# Custody event

A transfer of possession — a sale, a gift, a bequest, a loan, a seizure, a restitution — with
a date, the parties, and the document that records it.

It has to be a node rather than a row in the object's history field, because the interesting
questions are about the *events*: which of them rest on a single dealer's stockbook, which
have a date but no named party, which two sources describe incompatibly. None of those can be
asked of a prose paragraph, and provenance is conventionally written as a prose paragraph.
