# Event

A birth, a marriage, a death, a burial, an enumeration. Something that happened at a time and
a place, and the thing records actually attest.

It is irreducible because it is the join. A record attests an event; an event involves people.
Take the event away and the record has to attest a fact *about a person* directly — at which
point the person node accumulates fields, two records disagreeing have nowhere to disagree,
and the corpus is a genealogy program again.

The alignment question this domain has to answer lands here: a wedding is an occurrence with a
duration of an afternoon, and a marriage is a bond with a duration of decades. Whether those
are one node or two is the first real modelling decision, and it should be argued in the
dialogue rather than settled by whoever writes the class file.
