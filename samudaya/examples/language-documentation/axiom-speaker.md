# Speaker

A person who contributed recordings, as they wish to be identified.

A class rather than a field on the elicitation, because the questions worth asking are about a
speaker across sessions — how a form varies for one person over a decade, which speakers a
generalisation actually rests on, whether an analysis is describing a language or an idiolect.
A name written inside a session record cannot be asked any of those.

**Consent is not this class.** It is a property of an elicitation — scoped to a session, a date
and a stated purpose — and hoisting it here would let the corpus carry one blanket permission
covering recordings it was never granted for. That is the failure mode the class boundary
exists to prevent, and it should be argued in the dialogue rather than assumed.
