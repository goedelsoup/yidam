# A catalog entry says what the source may not be used for

Every registered source carries, explicitly, the uses it does **not** license — redistribution,
quotation beyond a length, use outside a named project, use without a community body's
agreement — alongside what it does answer.

Documentary linguistics has spent two decades building this discipline into its archives:
deposits carry access conditions, and the CARE principles for Indigenous data governance make
the point that a permission to *hold* material is not a permission to *publish* it. The
common failure is not a refusal recorded and ignored; it is a restriction that was agreed
verbally, never written into the catalog, and therefore invisible to everyone downstream who
had no reason to suspect it existed.

A catalog that records only what a source answers will be read as licensing everything it
does not forbid.
