# Every analytical claim cites the forms it rests on

Consider requiring an edge from any analysis — a paradigm, a phonological generalisation, a
grammatical description — to the attested forms supporting it, and consider making an
analysis with no such edge a finding rather than a normal state.

A generalisation nobody can trace to attestations is the failure mode this domain already
knows well: it survives into the reference grammar, gets cited, and cannot be rechecked when
the recordings are revisited a decade later.
