# Corpus

The nodes in this fixture, by class. A gauge measures a concept; concepts relate to and
refine one another.

This page links to [the gauge record](../catalog/gauge-record.md), and that link is the
point of it: a README is not a node, so the link is counted under **Elsewhere** in
`catalog-audit` and by no gate. Without it the fixture pins only the arm where both counts
are zero, which is the arm that could never have shown the defect.
