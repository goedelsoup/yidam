Git branch reference with automatic type-based color coding. The visual distinction between ma/* (rose) and rigpa/* (blue) is the primary UI signal for the collective knowledge protocol.

```jsx
<BranchRef branch="ma/alice" />                        {/* rose pill: ma/alice          */}
<BranchRef branch="rigpa/first-synthesis" />           {/* blue pill: rigpa/first-synthesis */}
<BranchRef branch="ma/alice" commit="3d8f2a1" />       {/* rose pill + @3d8f2a1         */}
<BranchRef branch="ma/agent-01" short />               {/* rose pill: agent-01          */}
```
