Phase type indicator for agent inquiry phases. Small-caps uppercase label in phase-specific tint.

```jsx
<PhaseTag phase="Investigation" />   {/* rigpa-blue tint */}
<PhaseTag phase="Extraction" />      {/* gold tint       */}
<PhaseTag phase="Synthesis" />       {/* ma-rose tint    */}
<PhaseTag phase="Assessment" />      {/* green tint      */}
```

**Color mapping:**
- Investigation → rigpa-blue (exploration, open inquiry)
- Extraction → gold (structured data retrieval)
- Synthesis → ma-rose (individual positions converging)
- Assessment → green (evaluation, narrowing)
