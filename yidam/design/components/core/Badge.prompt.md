Small semantic label for status, category, or epistemic state.

```jsx
<Badge variant="gold">genesis</Badge>
<Badge variant="rigpa" dot>rigpa/first-synthesis</Badge>
<Badge variant="verified">verified</Badge>
<Badge variant="open" size="sm">open question</Badge>
```

**Variants:** `default` · `gold` · `rigpa` · `ma` · `verified` · `inference` · `open` · `inverse`

**Note:** For inline epistemic annotation within prose, prefer `ClaimMarker` (monospace font, bracket format). `Badge` is for UI metadata labels — status indicators, branch types, counts.
