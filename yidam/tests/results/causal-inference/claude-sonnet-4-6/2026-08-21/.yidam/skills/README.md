# skills

Domain-specific skills available to agents in this repository. Generic skills inherited
from yidam live in [`.yidam/.vendor/prelude/skills/`](../.vendor/prelude/skills/); skills that require
knowledge of this domain's corpus or toolkit live here.

Domain skills anticipated for this corpus:

- **identification-check** — evaluates whether a proposed identification strategy satisfies
  its required assumptions given the study design and confounding structure
- **assumption-audit** — traces which assumptions underlie a given estimator and marks each
  as `[verified]`, `[inference]`, or `[open]` relative to current corpus evidence
- **phase-summary** — distills a completed phase into a synthesis node linking findings
  to the relevant estimands and assumptions

Add skills when a repeatable procedure emerges from inquiry — not preemptively.
