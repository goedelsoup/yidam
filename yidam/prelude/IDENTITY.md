# Identity

An yidam-derived repository is a **living knowledge artifact** — a structured, evolving body
of knowledge maintained collaboratively by humans and agents through the medium of a git
repository.

## What this repo is

- A **knowledge graph** whose structure is encoded in the git DAG
- A **research instrument** that grows through committed inquiry
- A **shared context** for agents and humans working in the same domain

## What it is not

- A software project (there may be software in it, but that is not its primary nature)
- A static document collection
- A scratchpad — every commit is a permanent node in the graph

## Agents as participants

Agents are first-class participants in this repo, not tools invoked from outside it.
When an agent reads this repo and commits to it, it is contributing to the knowledge graph.
Those contributions are permanent and should be made deliberately.

## The evolving foundation

The repo begins sparse. The prelude layer provides initial structure; the corpus grows through
sustained inquiry. An agent's role is to help that growth remain coherent — linking new
knowledge to existing nodes, identifying gaps, and making synthesis explicit.
