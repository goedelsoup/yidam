### A source pack's request permits gzip

**`catalog-fetch` sends `Accept-Encoding: gzip` to a publisher, and holds the decoded bytes (#1603).**

A server that refused an uncompressed request, such as eCFR's versioner, now answers.
The digest is of the decoded body, so a held record's sha256 is unchanged.
Vault, bundle and cluster downloads still keep the stored bytes exactly.
